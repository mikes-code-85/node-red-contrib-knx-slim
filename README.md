## About
Based on Supergiovane/node-red-contrib-knx-ultimate. To decrease amount of required updates and to reduce attack surface this package removed most (all?) non-KNX related code and dependencies (matter / google translate / mqtt) from the original package - hence the name "slim".<br>
The original repository with the amazing work of Supergiovane can be found here: [Supergiovane/node-red-contrib-knx-ultimate](https://github.com/Supergiovane/node-red-contrib-knx-ultimate)<br>
